## 1. 재현성 (Reproducibility)

### ✅ 의존성 목록 (`requirements.txt`)
본 분석은 **Python 3.13.16** 환경에서 수행되었으며, 아래의 라이브러리 설치가 필요합니다.

```text
pandas>=1.3.0
numpy>=1.21.0
matplotlib>=3.4.0
yfinance>=0.2.0
pandas_ta>=0.3.14b
```

### 🚀 실행 방법
1.  **환경 구축**: Python 환경(Anaconda 또는 가상환경)을 준비합니다.
2.  **패키지 설치**: 터미널에서 `pip install -r requirements.txt`를 실행합니다.
3.  **코드 실행**: Jupyter Notebook(`*.ipynb`) 파일을 열고 **[Run All]**을 클릭하여 순차적으로 실행합니다.
4.  **인터넷 연결**: `yfinance`를 통한 실시간 데이터 수집을 위해 **인터넷 연결**이 필수입니다.

### 📊 데이터 출처 및 라이선스
*   **데이터 출처**: Yahoo Finance (Ticker: `005930.KS`)
*   **수집 방법**: `yfinance` 라이브러리를 이용한 API 호출
*   **법적 고지**: 본 데이터는 **학습 및 분석 연습용**이며, 실제 투자 결과에 대한 책임을 지지 않습니다.
